# SH1106 — 128×64 OLED Display

The **SH1106** is similar to SSD1306 but uses **132×64 internal RAM** with a **2-column offset** — common on cheap 1.3″ OLED modules.

**Prerequisites:** [ssd1306.md](./ssd1306.md), [17-i2c.md](../17-i2c.md)

---

## Working Principle

Same OLED pixel technology as SSD1306. SH1106 maps visible 128 columns starting at **column 2** internally — driver must add +2 column offset or text appears shifted.

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| Visible | 128×64 |
| Internal RAM | 132×64 |
| I²C address | `0x3C` / `0x3D` |
| Column offset | +2 typical |

---

## Protocol

Identical I²C/SPI command set to SSD1306 for most commands. Column addressing uses **page mode** (lower nibble commands `0x00`–`0x0F`, `0x10`–`0x1F`) rather than `0x21` window on some init paths.

See [17-i2c.md](../17-i2c.md).

---

## Register Map

Same command opcodes as SSD1306 — see [ssd1306.md](./ssd1306.md). Key difference is **column offset 2** when setting lower/higher column address nibbles.

---

## ESP32-S3 Wiring

Same as SSD1306:

```
SDA → GPIO8, SCL → GPIO9, VCC → 3V3, GND → GND
```

Optional RST → GPIO15 per [08-gpio.md](../08-gpio.md).

## Swift Driver Sketch

```swift
struct SH1106<B: I2CBus> {
    var bus: B
    let address: UInt8 = 0x3C
    let columnOffset: UInt8 = 2
    var buffer: [UInt8] = [UInt8](repeating: 0, count: 1024)

    mutating func flush() throws {
        for page in 0..<8 {
            try sendCommand(0xB0 | UInt8(page))
            try sendCommand(columnOffset & 0x0F)        // lower column + offset
            try sendCommand(0x10 | ((columnOffset >> 4) & 0x0F)) // higher column
            let start = page * 128
            var chunk = [UInt8(0x40)] + Array(buffer[start..<(start + 128)])
            try bus.write(to: address, data: chunk)
        }
    }

    private mutating func sendCommand(_ cmd: UInt8) throws {
        try bus.write(to: address, data: [0x00, cmd])
    }
}
```

---

## Bare-Metal Notes

- Do not use SSD1306 horizontal addressing init blindly — SH1106 often needs page mode flush.
- If image shifted left/right by 2 px, adjust `columnOffset`.

---

## HAL / Protocol-Oriented Driver Notes

Share drawing code with SSD1306 via common `MonoDisplay128x64` protocol; only `flush()` and init differ.
