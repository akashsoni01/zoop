# GC9A01 — 240×240 Round TFT

The **GC9A01** controller drives **circular 240×240** IPS displays — common for gauge and watch-style UIs.

**Prerequisites:** [16-spi.md](../16-spi.md), [st7789.md](./st7789.md)

---

## Working Principle

Same SPI RGB565 paradigm as ST7789/ILI9341 but with **round active area** inscribed in 240×240 square GRAM. Init sequence is vendor-specific with many undocumented tuning registers.

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| Resolution | 240×240 round |
| Interface | SPI |
| Color | RGB565 |
| Visible area | Circular, corners black |

---

## Protocol

4-wire SPI identical to ST7789 wiring. Init sequence longer — use proven register table from reference drivers.

See [16-spi.md](../16-spi.md).

---

## Register Map

Uses standard MIPI-DCS-like opcodes plus manufacturer extended commands (`0xF0`–`0xFF` bank select):

| Cmd | Code | Description |
|-----|------|-------------|
| `0xFE` / `0xEF` | Inter register enable | Unlock extended regs |
| MADCTL | `0x36` | Orientation |
| COLMOD | `0x3A` | RGB565 |
| RAMWR | `0x2C` | Pixel data |

Full init ~50+ register writes.

---

## ESP32-S3 Wiring

Same SPI pinout as ST7789:

```
CS=GPIO10, DC=GPIO14, RST=GPIO15, MOSI=GPIO11, SCK=GPIO12, BL=GPIO16
```

See [08-gpio.md](../08-gpio.md) for reset timing.

## Swift Driver Sketch

```swift
let gc9a01Init: [(UInt8, [UInt8])] = [
    (0xFE, []), (0xEF, []),
    (0xEB, [0x14]),
    (0x84, [0x40]),
    // ... full vendor table ...
    (0x29, []), // DISPON
]

struct GC9A01<S: SPIBus> {
    var spi: S
    var dc: any DigitalPin
    var cs: any DigitalPin

    mutating func initDisplay() throws {
        for (cmd, data) in gc9a01Init {
            try writeCommand(cmd, data: data)
        }
    }

    mutating func fillCircle(cx: Int, cy: Int, r: Int, color: UInt16) throws {
        // Clip to bounding box; per-pixel distance test or precomputed mask
        let r2 = r * r
        for y in (cy - r)...(cy + r) {
            for x in (cx - r)...(cx + r) {
                let d = (x - cx) * (x - cx) + (y - cy) * (y - cy)
                if d <= r2 { try drawPixel(x: x, y: y, color: color) }
            }
        }
    }
}
```

---

## Bare-Metal Notes

- Round mask: skip pixels outside radius 120 from center (120,120) for clean circular UI.
- Extended register unlock sequence required before standard DCS commands.
- Share SPI bus with other devices — unique CS pin.

---

## HAL / Protocol-Oriented Driver Notes

Extend `ColorDisplay` with `CircularClip` helper. Init table stored as static resource in flash.

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Garbled boot | Incomplete init | Use full GC9A01 table |
