# SSD1306 — 128×64 OLED Display

Monochrome **OLED** controller supporting **I²C** and **SPI** — the most common small display in Embedded Swift projects.

**Prerequisites:** [17-i2c.md](../17-i2c.md), [16-spi.md](../16-spi.md), [08-gpio.md](../08-gpio.md)

---

## Working Principle

**OLED** pixels emit light directly — no backlight. The **SSD1306** controller drives a 128×64 dot matrix:

- **GDDRAM**: 1 bit per pixel, 1024 bytes total
- **Page addressing**: 8 vertical pages × 128 columns
- Contrast via charge pump command `0x81`

| Parameter | Value |
|-----------|-------|
| Resolution | 128×64 |
| I²C address | `0x3C` or `0x3D` |
| Supply | 3.3 V (some 5 V tolerant modules) |
| Interface | I²C, SPI 4-wire |
| Controller | SSD1306 |

---

## Protocol

### I²C

Control byte: `0x00` = command stream, `0x40` = GDGRAM data.

### SPI

DC low → command; DC high → data. CS active low per [16-spi.md](../16-spi.md).

---

## Register Map (Commands)

| Cmd | Code | Description |
|-----|------|-------------|
| DISPLAY OFF | `0xAE` | Sleep |
| DISPLAY ON | `0xAF` | Wake |
| SET_CONTRAST | `0x81` | 0–255 |
| MEMORY MODE | `0x20` | Horizontal / vertical / page |
| COLUMN ADDR | `0x21` | 0–127 |
| PAGE ADDR | `0x22` | 0–7 |
| CHARGE PUMP | `0x8D` | Enable `0x14` |

No readable status registers on most modules — command-only interface.

```
GND  ─────────────► GND

SCL  ─────────────► GPIO9
```

### SPI Variant

```
D0 (CLK)  ◄──────── GPIO12 (SCK)
D1 (MOSI) ◄──────── GPIO11
DC        ◄──────── GPIO14
RST       ◄──────── GPIO15
CS        ◄──────── GPIO10
```

## Swift Driver Sketch

```swift
protocol I2CBus {
    func write(to address: UInt8, data: [UInt8]) throws
}

struct SSD1306<B: I2CBus> {
    var bus: B
    let address: UInt8 = 0x3C
    var buffer: [UInt8] = [UInt8](repeating: 0, count: 1024)

    mutating func initDisplay() throws {
        let cmds: [UInt8] = [
            0xAE, 0xD5, 0x80, 0xA8, 0x3F, 0xD3, 0x00,
            0x8D, 0x14, 0x20, 0x00, 0xA1, 0xC8,
            0xDA, 0x12, 0x81, 0xCF, 0xD9, 0xF1,
            0xDB, 0x40, 0xA4, 0xA6, 0xAF
        ]
        for cmd in cmds { try sendCommand(cmd) }
    }

    mutating func setPixel(x: Int, y: Int, on: Bool) {
        guard (0..<128).contains(x), (0..<64).contains(y) else { return }
        let idx = x + (y / 8) * 128
        let bit = UInt8(1 << (y & 7))
        if on { buffer[idx] |= bit } else { buffer[idx] &= ~bit }
    }

    mutating func flush() throws {
        try sendCommand(0x21); try sendCommand(0); try sendCommand(127)
        try sendCommand(0x22); try sendCommand(0); try sendCommand(7)
        var frame = [UInt8(0x40)] + buffer
        try bus.write(to: address, data: frame)
    }

    private mutating func sendCommand(_ cmd: UInt8) throws {
        try bus.write(to: address, data: [0x00, cmd])
    }
}
```

## Bare-Metal Notes

- Wait ≥100 ms after power-up before init.
- Toggle reset pin LOW 10 ms, HIGH 10 ms before command sequence.
- I²C clock 400 kHz typical; 1 MHz possible on short wires.

---

## HAL / Protocol-Oriented Driver Notes

Implement `Display128x64` protocol: `setPixel`, `flush`, `clear`. Drawing primitives (text, lines) as extensions on framebuffer.

---

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Blank screen | Charge pump off | Send `0x8D 0x14` |
| Dim pixels | Low contrast | Raise contrast command |
| Wrong address | SA0 pin | Try `0x3D` |
| SPI garbage | DC swapped | DC=cmd vs data |
