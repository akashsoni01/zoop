# ST7789 — 240×240 IPS TFT

The **Sitronix ST7789** drives **240×240** (and 135×240) **IPS** TFT panels — popular on 1.3″ and 1.54″ displays.

**Prerequisites:** [16-spi.md](../16-spi.md), [08-gpio.md](../08-gpio.md)

---

## Working Principle

Similar to ILI9341: SPI commands configure GRAM; RGB565 pixel stream fills display. IPS provides wide viewing angles. Some modules offset visible area (240×240 in 240×320 driver IC).

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| Resolution | 240×240 typical |
| Interface | 4-wire SPI |
| Pixel format | RGB565 (`0x55`) |
| ID | `0x85` readable |

---

## Protocol

SPI mode 0, DC/CS/RST same pattern as ILI9341. Init sequence differs — include **COLMOD**, **MADCTL**, **PORCH**, **GCTRL**, **VCOMS**, **LCM**, **VRHS**, **VDVRS** vendor tuning.

See [16-spi.md](../16-spi.md).

---

## Register Map

| Cmd | Code | Description |
|-----|------|-------------|
| SWRESET | `0x01` | Reset |
| SLPOUT | `0x11` | Sleep out |
| INVON | `0x21` | Some modules need inversion |
| MADCTL | `0x36` | Orientation |
| COLMOD | `0x3A` | `0x55` RGB565 |
| CASET | `0x2A` | Column |
| RASET | `0x2B` | Row |
| RAMWR | `0x2C` | Pixel write |
| DISPON | `0x29` | On |

## Swift Driver Sketch

```swift
struct ST7789<S: SPIBus> {
    var spi: S
    var dc: any DigitalPin
    var cs: any DigitalPin
    let width: Int = 240
    let height: Int = 240

    mutating func initDisplay() throws {
        try writeCommand(0x11); delayMs(120)
        try writeCommand(0x3A, data: [0x55])
        try writeCommand(0x36, data: [0x00]) // MADCTL
        try writeCommand(0x21) // INVON — module dependent
        try writeCommand(0x29)
    }

    mutating func drawLineBuffer(y: Int, pixels: [UInt16]) throws {
        try setWindow(x: 0, y: y, w: width, h: 1)
        try writeCommand(0x2C)
        var bytes = [UInt8]()
        bytes.reserveCapacity(pixels.count * 2)
        for p in pixels {
            bytes.append(UInt8(p >> 8))
            bytes.append(UInt8(p & 0xFF))
        }
        try writeData(bytes)
    }
}
```

## Bare-Metal Notes

- 135×240 modules: apply X/Y offset (often 52, 40) in CASET/RASET.
- Try INVON vs INVOFF if colors look photographic-negative.
- 40 MHz SPI possible on short wires with ESP32-S3.

---

## HAL / Protocol-Oriented Driver Notes

Same `ColorDisplay` protocol as ILI9341. Share SPI transport layer; differ only init table and offsets.

---

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Offset image | Wrong XY offset | Add module-specific offset |
| Negative colors | Inversion | Toggle INVON/INVOFF |
| Flicker | Full screen rewrite | Use line buffer updates |
