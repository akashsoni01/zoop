# Embedded Swift Projects

Complete **tutorial builds** combining lessons, [examples/](../examples/README.md), [communication/](../communication/README.md) protocols, and [sensors/](../sensors/README.md) / [displays/](../displays/README.md).

**Primary platform:** ESP32-S3 DevKitC-1

---

## How to Use

1. Review **Prerequisites** and **BOM** before ordering parts.
2. Wire per ASCII diagram; verify with multimeter.
3. Follow **Firmware plan** milestones — flash and test each step.
4. Complete **Testing** checklist before extensions.
