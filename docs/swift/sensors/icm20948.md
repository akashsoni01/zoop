# ICM-20948 — 9-Axis IMU

The **TDK InvenSense ICM-20948** is a modern 9-DoF IMU with integrated accel, gyro, and AK09916 magnetometer. Popular upgrade over MPU-9250.

**Prerequisites:** [imu-overview.md](./imu-overview.md), [17-i2c.md](../17-i2c.md), [16-spi.md](../16-spi.md)

---

## Working Principle

Three sensors in one package connected via internal **I²C master** (bank-switched register map). Accel/gyro front-end similar to ICM-20649; magnetometer accessed through auxiliary I²C port.

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| I²C address | `0x68` / `0x69` |
| WHO_AM_I | `0xEA` (bank 0) |
| Accel FSR | ±2, ±4, ±8, ±16 g |
| Gyro FSR | ±250 … ±2000 °/s |
| Mag | AK09916, ±4900 µT |

---

## Protocol

**Bank switching:** Register `0x7F` selects bank 0–3. WHO_AM_I and power in bank 0; gyro/accel config in bank 2; I²C master in bank 3.

I²C or SPI (mode 0 or 3). See [17-i2c.md](../17-i2c.md) / [16-spi.md](../16-spi.md).

---

## Register Map (Bank 0 essentials)

| Addr | Name | Description |
|------|------|-------------|
| `0x7F` | `REG_BANK_SEL` | Bank select |
| `0x00` | WHO_AM_I | `0xEA` |
| `0x06` | PWR_MGMT_1 | Sleep, reset, clock |
| `0x03`–`0x08` | Accel data | Big-endian XYZ |
| `0x2D`–`0x32` | Gyro data | Big-endian XYZ |

### Bank 3 — I²C Master (mag access)

| Addr | Name | Description |
|------|------|-------------|
| `0x03` | I2C_SLV0_ADDR | Mag `0x0C` read |
| `0x04` | I2C_SLV0_REG | Mag data register |
| `0x05` | I2C_SLV0_CTRL | Enable, length |

## Swift Driver Sketch

```swift
struct ICM20948<B: I2CBus> {
    var bus: B
    let address: UInt8 = 0x68
    var bank: UInt8 = 0

    mutating func selectBank(_ b: UInt8) throws {
        guard b <= 3 else { return }
        try bus.write(to: address, register: 0x7F, data: [b << 4])
        bank = b
    }

    mutating func initDevice() throws {
        try selectBank(0)
        guard try bus.read(from: address, register: 0x00, count: 1)[0] == 0xEA else {
            throw SensorError.wrongDevice
        }
        try bus.write(to: address, register: 0x06, data: [0x01]) // auto clock
        try setupMagSlave()
    }

    mutating func setupMagSlave() throws {
        try selectBank(3)
        try bus.write(to: address, register: 0x03, data: [0x8C]) // 0x0C | READ
        try bus.write(to: address, register: 0x04, data: [0x11]) // ST1 reg
        try bus.write(to: address, register: 0x05, data: [0x89]) // enable, 9 bytes
        try selectBank(0)
    }

    mutating func readAccel() throws -> Vec3f {
        try selectBank(0)
        let d = try bus.read(from: address, register: 0x2D, count: 6)
        return parseBigEndian(d, scale: 16384.0)
    }
}
```

## Bare-Metal Notes

- Always restore bank 0 after bank-specific operations.
- Soft reset via `PWR_MGMT_1` bit 7; wait 100 ms.
- Enable DLPF in bank 2 for stable readings.

---

## HAL / Protocol-Oriented Driver Notes

Wrap bank switching in private `withBank(_:body:)` helper. Implement `IMU9Axis`. Consider SPI for higher ODR to reduce bus overhead.

---

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| WHO_AM_I wrong bank | Forgot bank select | Write `REG_BANK_SEL` first |
| Mag stale data | Slave not enabled | Re-run `setupMagSlave()` |
| Clone chip | Incompatible map | Verify WHO_AM_I |
