# MAX30102 — Pulse Oximeter / PPG

The **Maxim MAX30102** integrates **red and IR LEDs** with photodetector for **photoplethysmography (PPG)** — heart rate and SpO₂ estimation.

**Prerequisites:** [17-i2c.md](../17-i2c.md)

---

## Working Principle

LEDs alternately illuminate tissue; photodiode measures reflected/absorbed light. Pulsatile blood volume changes AC component of signal — processed for **heart rate (BPM)** and **SpO₂** via ratio-of-ratios (IR vs red).

| Parameter | Value |
|-----------|-------|
| I²C address | `0x57` |
| Part ID (`0xFF`) | `0x15` |
| LED currents | 0–50 mA programmable |
| Sample rates | 50–3200 sps |
| FIFO | 32 samples depth |

---

## Protocol

**I²C** register access. FIFO burst read for efficient sampling.

See [17-i2c.md](../17-i2c.md).

---

## Register Map

| Addr | Name | Description |
|------|------|-------------|
| `0x09` | FIFO_WR_PTR | Write pointer |
| `0x0A` | FIFO_RD_PTR | Read pointer |
| `0x0C` | FIFO_DATA | Burst read 3 bytes/sample |
| `0x0D` | FIFO_CONFIG | Sample averaging |
| `0x0E` | MODE_CONFIG | SpO₂ vs HR-only mode |
| `0x0F` | SPO2_CONFIG | ADC range, sample rate |
| `0x10`–`0x12` | LED currents | Red / IR drive |
| `0xFF` | PART_ID | `0x15` |

Each FIFO sample: 18-bit red + 18-bit IR (3 bytes each, 6 bytes total).

## ESP32-S3 Wiring

```
ESP32-S3          MAX30102
────────          ───────
GPIO8  ─────────► SDA
GPIO9  ─────────► SCL
3V3    ─────────► VCC
GND    ─────────► GND
GPIO7  ─────────► INT (FIFO almost full)
```

Finger must cover LED and sensor window firmly.

## Swift Driver Sketch

```swift
struct PPGSample: Sendable {
    var red: UInt32
    var ir: UInt32
}

struct MAX30102<B: I2CBus> {
    var bus: B
    let address: UInt8 = 0x57

    mutating func initDevice() throws {
        try bus.write(to: address, register: 0x09, data: [0x00]) // reset FIFO
        try bus.write(to: address, register: 0x0E, data: [0x03]) // SpO2 mode
        try bus.write(to: address, register: 0x0F, data: [0x27]) // 100 Hz, 4096 nA
        try bus.write(to: address, register: 0x10, data: [0x24]) // red current
        try bus.write(to: address, register: 0x11, data: [0x24]) // IR current
    }

    mutating func readFIFO() throws -> PPGSample? {
        let count = try bus.read(from: address, register: 0x07, count: 1)[0] & 0x1F
        guard count > 0 else { return nil }
        let d = try bus.read(from: address, register: 0x0C, count: 6)
        let red = (UInt32(d[0]) << 16 | UInt32(d[1]) << 8 | UInt32(d[2])) & 0x3FFFF
        let ir  = (UInt32(d[3]) << 16 | UInt32(d[4]) << 8 | UInt32(d[5])) & 0x3FFFF
        return PPGSample(red: red, ir: ir)
    }
}
```

## Bare-Metal Notes

- Motion artifacts dominate — keep finger still.
- FIFO interrupt reduces polling overhead at 100 Hz.
- SpO₂ algorithm needs calibration; hobby accuracy is approximate.

---

## HAL / Protocol-Oriented Driver Notes

Split `MAX30102` transport from `PPGProcessor` (filter, peak detect, SpO₂ math). Signal processing runs on host or second task.

---

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Flat line | LED current too low | Increase `0x10`/`0x11` |
| Saturated | Too much pressure | Loosen finger contact |
| FIFO overflow | Read too slow | Enable INT; read at 100 Hz |
