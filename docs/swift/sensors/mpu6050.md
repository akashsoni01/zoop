# MPU-6050 — 6-Axis IMU

The **InvenSense MPU-6050** is a widely available 6-DoF IMU on I²C. See [imu-overview.md](./imu-overview.md) for theory.

**Prerequisites:** [imu-overview.md](./imu-overview.md), [17-i2c.md](../17-i2c.md)

---

## Working Principle

Single-die integration of 3-axis MEMS accelerometer and 3-axis MEMS gyroscope with an optional digital motion processor (**DMP**). Most Embedded Swift projects read raw registers directly.

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| VDD | 2.375–3.46 V |
| I²C address | `0x68` (AD0=0), `0x69` (AD0=1) |
| WHO_AM_I (`0x75`) | `0x68` |
| Gyro FSR | ±250, ±500, ±1000, ±2000 °/s |
| Accel FSR | ±2, ±4, ±8, ±16 g |

---

## Protocol

**I²C** up to 400 kHz. 16-bit registers are **big-endian** (high byte first). Optional **INT** pin (active low): data ready, motion interrupt, FIFO overflow.

---

## Register Map

| Addr | Name | Description |
|------|------|-------------|
| `0x6B` | `PWR_MGMT_1` | Sleep, clock source, reset |
| `0x6C` | `PWR_MGMT_2` | Disable axes |
| `0x1A` | `CONFIG` | DLPF setting |
| `0x1B` | `GYRO_CONFIG` | Gyro FSR (bits 4:3) |
| `0x1C` | `ACCEL_CONFIG` | Accel FSR (bits 4:3) |
| `0x43`–`0x48` | Sensor data | Gyro XYZ, Accel XYZ |
| `0x41`–`0x42` | TEMP | Temperature |
| `0x75` | WHO_AM_I | Device ID |

### Scaling (±2g accel, ±250 °/s gyro)

| Sensor | LSB/unit |
|--------|----------|
| Accel ±2g | 16384 LSB/g |
| Gyro ±250 °/s | 131 LSB/(°/s) |

## ESP32-S3 Wiring

```
ESP32-S3          MPU-6050 Module
────────          ───────────────
GPIO8  (SDA) ───► SDA
GPIO9  (SCL) ───► SCL
3V3          ───► VCC
GND          ───► GND
GPIO7        ───► INT (optional)
```

AD0: GND → `0x68`, 3V3 → `0x69`.

## Swift Driver Sketch

```swift
struct MPU6050<B: I2CBus>: IMU6Axis {
    var bus: B
    let address: UInt8 = 0x68
    var accelScale: Float = 16384.0
    var gyroScale: Float = 131.0

    mutating func initDevice() throws {
        guard try bus.read(from: address, register: 0x75, count: 1)[0] == 0x68 else {
            throw SensorError.wrongDevice
        }
        try bus.write(to: address, register: 0x6B, data: [0x01]) // wake, PLL
        try bus.write(to: address, register: 0x1A, data: [0x03]) // DLPF 44 Hz
        try bus.write(to: address, register: 0x1B, data: [0x00]) // gyro ±250
        try bus.write(to: address, register: 0x1C, data: [0x00]) // accel ±2g
    }

    mutating func readAccel() throws -> Vec3f {
        let d = try bus.read(from: address, register: 0x3B, count: 6)
        return scaleAccel(d)
    }

    mutating func readGyro() throws -> Vec3f {
        let d = try bus.read(from: address, register: 0x43, count: 6)
        return scaleGyro(d)
    }

    private func scaleAccel(_ d: [UInt8]) -> Vec3f {
        func i16(_ i: Int) -> Int16 {
            Int16(bitPattern: UInt16(d[i]) << 8 | UInt16(d[i+1]))
        }
        return Vec3f(x: Float(i16(0)) / accelScale,
                     y: Float(i16(2)) / accelScale,
                     z: Float(i16(4)) / accelScale)
    }
}
```

---

## Bare-Metal Notes

- Clear sleep bit (bit 6) in `PWR_MGMT_1`; wait ~100 ms after wake.
- Burst-read from `0x3B` gets accel + temp + gyro in one transaction (14 bytes).
- INT pin useful for 100 Hz sampling without polling.

---

## HAL / Protocol-Oriented Driver Notes

Implement `IMU6Axis` protocol. Expose FSR configuration as enum (`AccelRange`, `GyroRange`) that updates scale factors. Keep register constants in a nested `Register` enum.

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| WHO_AM_I 0x70 | MPU-9250 in MPU6050 mode | Use [mpu9250.md](./mpu9250.md) |
| All zeros | Still in sleep | Write `PWR_MGMT_1 = 0x01` |
| I²C NACK | AD0 address | Try `0x69` |
