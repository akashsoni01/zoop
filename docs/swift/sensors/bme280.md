# BME280 — Pressure, Temperature & Humidity

The **Bosch BME280** combines barometric pressure, temperature, and **relative humidity** in one package. It shares the BMP280 pressure/temp front-end and adds a capacitive humidity sensor.

**Prerequisites:** [bmp280.md](./bmp280.md), [17-i2c.md](../17-i2c.md)

---

## Working Principle

Three independent elements on one die:

1. **Pressure** — piezo-resistive (same as BMP280)
2. **Temperature** — compensation for all channels
3. **Humidity** — capacitive polymer on a separate conversion path

All outputs are **factory trimmed**; compensation uses coefficients in registers `0x88`–`0xA1` (temp/press) and `0xE1`–`0xF0` (humidity).

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| `chip_id` (0xD0) | `0x60` |
| I²C address | `0x76` / `0x77` (SDO) |
| Humidity range | 0–100 %RH |
| Interface | I²C, SPI |

**Do not confuse with BMP280** (`chip_id = 0x58`) — always verify ID before init.

---

## Protocol

Identical bus mechanics to BMP280. See [bmp280.md](./bmp280.md) for I²C/SPI wiring on ESP32-S3 (GPIO8/9).

Humidity requires enabling **humidity oversampling** in `ctrl_hum` (`0xF2`) **before** writing `ctrl_meas`.

---

## Register Map

| Addr | Name | Description |
|------|------|-------------|
| `0xD0` | `chip_id` | `0x60` |
| `0xE1`–`0xF0` | Humidity trim | `dig_H1`–`dig_H6` |
| `0x88`–`0x9F` | Temp/press trim | Shared with BMP280 layout |
| `0xF2` | `ctrl_hum` | Humidity oversampling only |
| `0xF4` | `ctrl_meas` | Temp, press OS + mode |
| `0xF5` | `config` | Filter, standby |
| `0xF7`–`0xFE` | Data | Press(3), Temp(3), Hum(2) |

### Init Sequence (Critical Order)

```text
1. Read chip_id → 0x60
2. Read all calibration registers
3. Write ctrl_hum (0xF2) — e.g. 0x01 (OS x1)
4. Write ctrl_meas (0xF4) — temp, press, mode
5. Write config (0xF5) — optional filter
6. Wait for first conversion
```

Skipping step 3 before step 4 leaves humidity disabled.

## Swift Driver Sketch

```swift
struct Bme280Calibration {
    var tempPress: Bmp280Calibration
    var h1: UInt8
    var h2: Int16, h3: Int8, h4: Int16, h5: Int16, h6: Int8
}

struct BME280<B: I2CBus> {
    var bus: B
    let address: UInt8
    var cal: Bme280Calibration
    var tFine: Int32 = 0

    mutating func initDevice() throws {
        guard try bus.read(from: address, register: 0xD0, count: 1)[0] == 0x60 else {
            throw SensorError.wrongDevice
        }
        cal = try loadCalibration()
        try bus.write(to: address, register: 0xF2, data: [0x01]) // hum OS first
        try bus.write(to: address, register: 0xF4, data: [0x27]) // temp+press+forced
        try bus.write(to: address, register: 0xF5, data: [0xA0])
    }

    mutating func read() throws -> (tempC: Double, pressurePa: Double, humidity: Double) {
        let d = try bus.read(from: address, register: 0xF7, count: 8)
        let adcP = unpack20(d[0], d[1], d[2])
        let adcT = unpack20(d[3], d[4], d[5])
        let adcH = (UInt16(d[6]) << 8) | UInt16(d[7])
        let temp = compensateTemp(adcT)
        let press = compensatePress(adcP)
        let hum = compensateHumidity(adcH)
        return (temp, press, hum)
    }

    private func compensateHumidity(_ adc: UInt16) -> Double {
        var v = Double(tFine) - 76800.0
        v = (Double(adc) - (Double(cal.h4) * 64.0 + Double(cal.h5) / 16384.0 * v))
            * (Double(cal.h2) / 65536.0 * (1.0 + Double(cal.h6) / 67108864.0 * v * (1.0 + Double(cal.h3) / 67108864.0 * v)))
        v *= (1.0 - Double(cal.h1) * v / 524288.0)
        return min(max(v, 0), 100)
    }
}
```

## Bare-Metal Notes

- Forced mode (`ctrl_meas` mode bits = `01`) triggers one shot — poll status or wait ~10 ms.
- Normal mode streams continuously; filter in `config` reduces noise at cost of latency.
- Keep sensor away from ESP32-S3 heat for accurate RH readings.

---

## HAL / Protocol-Oriented Driver Notes

Extend BMP280 driver with humidity calibration load and `ctrl_hum` ordering constraint. Expose `Bme280Reading` struct conforming to `Sendable` for async sensor tasks.

---

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Humidity always 0 | `ctrl_hum` not written first | Re-init with correct order |
| `chip_id` 0x58 | BMP280 module | Use [bmp280.md](./bmp280.md) driver |
| Sticky RH | Self-heating | Lower sample rate; add airflow |
