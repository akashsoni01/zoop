# BMP280 — Barometric Pressure & Temperature

The **Bosch BMP280** is a compact **MEMS barometer** with an integrated temperature sensor for compensation. Common in weather stations and altitude estimation.

**Prerequisites:** [17-i2c.md](../17-i2c.md)

---

## Working Principle

A **piezo-resistive pressure sensor** measures atmospheric pressure. A separate **temperature sensor** provides compensation. Factory calibration coefficients stored in OTP registers convert raw ADC values to physical units.

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| `chip_id` (0xD0) | `0x58` |
| I²C address | `0x76` / `0x77` (SDO pin) |
| Pressure range | 300–1100 hPa |
| Interface | I²C (up to 3.4 MHz) or SPI |
| VDD | 1.71–3.6 V |

Always read `chip_id` before init — do not confuse with BME280 (`0x60`).

---

## Protocol

**I²C:** Write register address, then read burst. **SPI:** CS active low, bit 7 of first byte = read (1) / write (0).

See [17-i2c.md](../17-i2c.md) for ESP32-S3 wiring (GPIO8/9).

---

## Register Map

| Addr | Name | Description |
|------|------|-------------|
| `0xD0` | `chip_id` | Must read `0x58` |
| `0xE0` | `reset` | Write `0xB6` to soft reset |
| `0xF4` | `ctrl_meas` | Temp/press oversampling + mode |
| `0xF5` | `config` | IIR filter, standby time |
| `0xF7`–`0xFC` | Data | Press (3 B), Temp (3 B) |
| `0x88`–`0x9F` | Trim | Calibration coefficients |

### Init Sequence

```text
1. Read chip_id → 0x58
2. Read calibration 0x88–0x9F (24 bytes)
3. Write ctrl_meas: temp OS x2, press OS x16, normal mode
4. Write config: filter coefficient 4, standby 500 ms
5. Wait first conversion (~10 ms)
```

## ESP32-S3 Wiring

```
ESP32-S3          BMP280 Module
────────          ─────────────
GPIO8  (SDA) ───► SDA
GPIO9  (SCL) ───► SCL
3V3          ───► VCC
GND          ───► GND
```

SDO to GND → `0x76`; SDO to 3V3 → `0x77`.

## Swift Driver Sketch

```swift
struct Bmp280Calibration {
    var t1: UInt16, t2: Int16, t3: Int16
    var p1: UInt16, p2: Int16, p3: Int16, p4: Int16, p5: Int16, p6: Int16, p7: Int16, p8: Int16, p9: Int16
}

struct BMP280<B: I2CBus> {
    var bus: B
    let address: UInt8
    var cal: Bmp280Calibration = .init(t1: 0, t2: 0, t3: 0, p1: 0, p2: 0, p3: 0, p4: 0, p5: 0, p6: 0, p7: 0, p8: 0, p9: 0)
    var tFine: Int32 = 0

    mutating func initDevice() throws {
        let id = try bus.read(from: address, register: 0xD0, count: 1)[0]
        guard id == 0x58 else { throw SensorError.wrongDevice }
        let raw = try bus.read(from: address, register: 0x88, count: 24)
        cal = parseCalibration(raw)
        try bus.write(to: address, register: 0xF4, data: [0x57]) // normal mode
        try bus.write(to: address, register: 0xF5, data: [0x10])
    }

    mutating func read() throws -> (tempC: Double, pressurePa: Double) {
        let d = try bus.read(from: address, register: 0xF7, count: 6)
        let adcP = (UInt32(d[0]) << 12) | (UInt32(d[1]) << 4) | (UInt32(d[2]) >> 4)
        let adcT = (UInt32(d[3]) << 12) | (UInt32(d[4]) << 4) | (UInt32(d[5]) >> 4)
        let temp = compensateTemperature(adcT)
        let press = compensatePressure(adcP)
        return (temp, press)
    }

    private func compensateTemperature(_ adc: UInt32) -> Double { /* datasheet §4.2.3 */ 0 }
    private func compensatePressure(_ adc: UInt32) -> Double { /* datasheet §4.2.4 */ 0 }
    private func parseCalibration(_ raw: [UInt8]) -> Bmp280Calibration { .init(t1: 0, t2: 0, t3: 0, p1: 0, p2: 0, p3: 0, p4: 0, p5: 0, p6: 0, p7: 0, p8: 0, p9: 0) }
}
```

Altitude from pressure: `44330 * (1 - (P/P0)^0.1903)` with `P0 = 101325 Pa`.

---

## Bare-Metal Notes

- Burst-read `0xF7`–`0xFC` in one transaction to avoid skew between press/temp samples.
- After soft reset (`0xB6`), wait ≥2 ms before register access.
- SPI mode 3 (CPOL=1, CPHA=1) when using SPI variant.

---

## HAL / Protocol-Oriented Driver Notes

Split `BMP280` into: (1) register transport via `I2CBus`/`SPIBus`, (2) pure `Bmp280Compensation` struct testable on host. Use `Sendable` calibration blob loaded once at init.

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| `chip_id` wrong | BME280 or wiring | Check [bme280.md](./bme280.md) |
| Pressure drift | Heat from ESP32 | Mount sensor away from SoC; enable IIR filter |
| I²C NACK | SDO address | Try `0x76` and `0x77` |
| NaN altitude | P0 not set | Calibrate sea-level pressure for your location |
