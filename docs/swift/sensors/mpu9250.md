# MPU-9250 — 9-Axis IMU

The **InvenSense MPU-9250** combines MPU-6500 (6-axis) with AK8963 magnetometer in one package. Access via I²C or SPI.

**Prerequisites:** [mpu6050.md](./mpu6050.md), [imu-overview.md](./imu-overview.md), [17-i2c.md](../17-i2c.md)

---

## Working Principle

**6-axis IMU** (accel + gyro) shares the MPU-6050 register map at the primary I²C address. **3-axis magnetometer** (AK8963) is accessed through an **I²C master passthrough** inside the MPU or at secondary address `0x0C`.

---

## Datasheet Notes

| Parameter | Value |
|-----------|-------|
| IMU I²C | `0x68` / `0x69` |
| Mag I²C (direct) | `0x0C` |
| WHO_AM_I (IMU) | `0x71` |
| WHO_AM_I (mag) | `0x48` (register 0x00) |
| Mag range | ±4800 µT |

---

## Protocol

Primary: **I²C** to IMU registers (same as MPU-6050). Magnetometer: enable I²C bypass (`INT_PIN_CFG` bit 1) or use master mode (`I2C_MST_EN`) to read AK8963 at `0x0C`.

SPI variant uses [16-spi.md](../16-spi.md) wiring.

---

## Register Map

### IMU (MPU-6500 compatible)

Same as [mpu6050.md](./mpu6050.md) plus:

| Addr | Name | Description |
|------|------|-------------|
| `0x37` | `INT_PIN_CFG` | Bypass enable for mag |
| `0x24` | `I2C_MST_CTRL` | Master clock |
| `0x25` | `I2C_SLV0_ADDR` | Mag read addr `0x0C \| 0x80` |

### AK8963 Magnetometer

| Addr | Name | Description |
|------|------|-------------|
| `0x00` | WIA | ID `0x48` |
| `0x0A` | ST1 | Data ready |
| `0x03`–`0x08` | HXL–HZH | 16-bit XYZ (little-endian!) |
| `0x0C` | ST2 | Overflow flag |
| `0x0A` | CNTL1 | Mode: single measurement `0x01` |

## Swift Driver Sketch

```swift
struct MPU9250<B: I2CBus> {
    var bus: B
    let imuAddr: UInt8 = 0x68
    let magAddr: UInt8 = 0x0C

    mutating func initDevice() throws {
        guard try bus.read(from: imuAddr, register: 0x75, count: 1)[0] == 0x71 else {
            throw SensorError.wrongDevice
        }
        try bus.write(to: imuAddr, register: 0x6B, data: [0x01])
        // Enable I2C bypass to reach magnetometer directly
        try bus.write(to: imuAddr, register: 0x37, data: [0x02])
        try initMagnetometer()
    }

    mutating func initMagnetometer() throws {
        try bus.write(to: magAddr, register: 0x0A, data: [0x00]) // power down
        try bus.write(to: magAddr, register: 0x0A, data: [0x0F]) // Fuse ROM access
        let asa = try bus.read(from: magAddr, register: 0x10, count: 3)
        // Store sensitivity adjustment
        try bus.write(to: magAddr, register: 0x0A, data: [0x00])
        try bus.write(to: magAddr, register: 0x0A, data: [0x16]) // 16-bit, 100 Hz
    }

    mutating func readMag() throws -> Vec3f {
        try bus.write(to: magAddr, register: 0x0A, data: [0x01]) // single meas
        var st1: UInt8 = 0
        repeat { st1 = try bus.read(from: magAddr, register: 0x02, count: 1)[0] } while st1 & 0x01 == 0
        let d = try bus.read(from: magAddr, register: 0x03, count: 7)
        let st2 = d[6]
        guard st2 & 0x08 == 0 else { throw SensorError.overflow }
        // Parse little-endian mag data, apply ASA scale
        return Vec3f(x: 0, y: 0, z: 0)
    }
}
```

---

## Bare-Metal Notes

- Magnetometer data is **little-endian** (unlike IMU big-endian).
- Always check ST2 overflow bit — discard sample if set.
- Run mag at ≤100 Hz; higher rates increase noise.

---

## HAL / Protocol-Oriented Driver Notes

Split into `MPU6500` (6-axis) + `AK8963` (mag) structs sharing `I2CBus`. Implement `IMU9Axis` protocol wrapping both. Magnetometer calibration (hard/soft iron) as separate `MagCalibrator` type.

---

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Mag always 0 | Bypass not enabled | Set `INT_PIN_CFG = 0x02` |
| Overflow flag | Metal nearby | Move away from motors/batteries |
| Wrong WHO_AM_I | Clone chip | Verify register map matches |
