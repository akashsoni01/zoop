# MSP430 Board Guide

**Texas Instruments MSP430** — ultra-low-power 16-bit MCUs (e.g., MSP430FR2xx LaunchPad).

**Not supported** for Embedded Swift. Documented for curriculum completeness and honest toolchain comparison.

---

## Overview

| Spec | MSP430FR2433 LaunchPad |
|------|------------------------|
| **CPU** | MSP430 @ 16 MHz |
| **Flash (FRAM)** | 16 KB |
| **RAM** | 4 KB |
| **Power** | Sub-µA sleep modes |

---

## Embedded Swift Maturity

| Path | Status |
|------|--------|
| Embedded Swift | **Not viable** — RAM/flash far below Swift embedded minimums |
| TI C / Energia | Standard approach |
| Rust msp430 | Niche community support |

Use MSP430 for **analog ultra-low-power** designs in C; Swift on host for data aggregation — [24-low-power.md](../24-low-power.md) concepts apply across languages.

---

## Memory Map Overview

```
FRAM for code + data (unified)
4 KB SRAM
MMIO peripherals
```

---

## GPIO Notes

LaunchPad includes button (P1.1) and LED (P1.0) — verify FR2xx User's Guide. 3.3 V logic.

---

## Low-Power Reference Value

MSP430 excels at sleep modes — study TI docs even when implementing sleep on ESP32-S3 in Swift via ESP-IDF:

| MSP430 mode | Analog |
|-------------|--------|
| Active | ~100 µA/MHz class |
| LPM3 | sub-µA with RTC |

Port **wake source design patterns** to [24-low-power.md](../24-low-power.md) on Espressif targets.

---

## Swift Role

None on-device. Optional **host Swift** logger receiving UART telemetry from MSP430 C firmware.
