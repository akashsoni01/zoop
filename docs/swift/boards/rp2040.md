# RP2040 Board Guide

**Raspberry Pi Pico** — dual Cortex-M0+ @ 125 MHz, famous for **PIO** and low cost.

Embedded Swift: **blink example** in community repos; primary firmware often C (`pico-sdk`) or Rust (`embassy-rp`). Swift path is **experimental**.

---

## Overview

| Spec | Raspberry Pi Pico |
|------|-------------------|
| **CPU** | Dual Cortex-M0+ @ 125 MHz |
| **Flash** | External QSPI (2 MB on Pico) |
| **SRAM** | 264 KB |
| **Wi-Fi / BLE** | None (Pico W adds CYW43439) |
| **USB** | Device bootrom + SDK stack |

---

## Embedded Swift Maturity

| Path | Status |
|------|--------|
| Bare-metal blink | Community experiments |
| pico-sdk + Swift interop | Possible but immature |
| USB HID/CDC | Use C **tinyusb** + Swift app logic — [19-usb.md](../19-usb.md) |
| Host companion | macOS serial/USB tests |

For production USB lessons, Rust `embassy-rp` or C pico-sdk remains more mature; Swift for **application logic porting practice**.

---

## Memory Map Overview

```
0x0000_0000 ─── XIP flash (external)
0x2000_0000 ─── SRAM (264 KB)
0x4000_0000 ─── APB peripherals
0x5000_0000 ─── AHB (DMA, PIO, USB)
```

---

## GPIO Notes

Pico pinout:

| Pin | Label | Notes |
|-----|-------|-------|
| GP25 | — | Onboard LED |
| GP0/GP1 | UART0 | Default serial |
| GP16–GP19 | SPI0 | Common SPI |
| GP4/GP5 | I2C0 | Common I²C |

3.3 V logic; 5 V on VBUS only.

---

## Clock Tree

12 MHz crystal → PLL → 125 MHz system clock. USB requires 48 MHz PLL branch.

---

## Boot Sequence

ROM USB MSC (BOOTSEL) → flash second stage → user image. UF2 drag-and-drop or `picotool`.

---

## Peripherals

UART×2, SPI×2, I²C×2, **12 DMA channels**, **PIO×2**, USB device. Excellent [14-dma.md](../14-dma.md) reference platform.

---

## Swift Toolchain

- Target `armv6m-none-eabi` or platform-specific triple
- Linker script from pico-sdk
- **picotool** / OpenOCD (SWD on debug probe) for flash

Check [swift-embedded-examples](https://github.com/swiftlang/swift-embedded-examples) for RP2040 additions over time.

---

*Pico W: add Wi-Fi via CYW43439 — host Swift gateway often easier than MCU Swift Wi-Fi*
