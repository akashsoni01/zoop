# RS-232 — Legacy Serial Interface

**RS-232** is a **legacy serial** standard using ** bipolar voltages** (±3 V to ±15 V) for noise immunity over long cables. Modern MCUs use **3.3 V UART** — **MAX3232** level shifters bridge the gap.

**Prerequisites:** [uart-usart.md](./uart-usart.md)

---

## Theory

RS-232 defines:

| Signal | Function |
|--------|----------|
| TXD | Transmit data |
| RXD | Receive data |
| GND | Signal ground |
| RTS/CTS | Hardware flow control (optional) |
| DTR/DSR | Modem control (legacy) |

**Logic levels:** MARK (idle) = negative voltage; SPACE (active) = positive voltage — **inverted** vs TTL UART.

Common baud rates: 9600, 19200, 38400, 115200. Cable length up to **15 m** (official), longer at low baud.

---

## Timing Diagram (ASCII)

RS-232 byte 0x55 (same framing as UART, different voltage):

```
Idle (MARK, negative) ─────────────────────────────

START(SPACE) D0 D1 D2 D3 D4 D5 D6 D7 STOP(MARK)
   +V          alternating bits...
   
TTL side (via MAX3232):

MCU TX (3.3V) ───► MAX3232 ───► ±V RS-232 TXD ───► PC RX
```

---

## Packet Format

RS-232 is a **byte stream** — same application framing as [uart-usart.md](./uart-usart.md):

| Layer | Example |
|-------|---------|
| Raw | Modbus RTU, proprietary |
| Line | NMEA, AT commands |
| Binary | Length-prefixed frames |

Settings typically **9600 8N1** or **115200 8N1** on industrial gear.

---

## Electrical Characteristics

| Parameter | RS-232 | ESP32 UART |
|-----------|--------|------------|
| MARK (1) | −3 to −15 V | 3.3 V HIGH |
| SPACE (0) | +3 to +15 V | 0 V LOW |
| Max cable | ~15 m | ~1 m TTL |
| Driver | MAX3232, SP3232 | Native 3.3 V |

**Never** connect RS-232 directly to ESP32 GPIO — permanent damage.

## Swift HAL Sketch

```swift
import Embedded
import ESP32Hardware

struct RS232Link {
    var uart: UART1  // 3.3 V TTL side of MAX3232

    init(baud: UInt32 = 115200) {
        uart = UART1(baud: baud, tx: GPIO17, rx: GPIO18)
    }

    func writeLine(_ line: String) {
        var bytes = Array(line.utf8)
        bytes.append(0x0D)  // CR
        bytes.append(0x0A)  // LF
        uart.write(bytes)
    }
}
```

Hardware MAX3232 handles level conversion — Swift only sees TTL UART.

## Common Mistakes

1. **Direct RS-232 to MCU** — destroyed GPIO.
2. **Null modem confusion** — cross TX/RX and DTR/DSR as needed.
3. **Assuming 5 V tolerant** — use 3.3 V transceiver.
4. **Wrong baud** — garbled characters.
5. **No common ground** — floating reference.
