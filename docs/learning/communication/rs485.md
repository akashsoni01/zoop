# RS-485 — Differential Serial Bus

**RS-485** is a **half-duplex differential** bus for **multi-drop** serial networks up to hundreds of meters — industrial sensors, building automation, Modbus RTU.

**Prerequisites:** [uart-usart.md](./uart-usart.md), [rs232.md](./rs232.md)

---

## Theory

Uses **A** and **B** differential pair: logic determined by **V(A) − V(B)**.

| State | V(A−B) |
|-------|--------|
| Mark (1) | −200 mV to −6 V |
| Space (0) | +200 mV to +6 V |

**Half-duplex:** one driver active at a time. **DE** (Driver Enable) and **RE** (Receiver Enable) pins on transceivers (MAX485, SN65HVD).

Termination **120 Ω** at bus ends; **bias resistors** (e.g., 560 Ω pull-up, 560 Ω pull-down) for idle state.

---

## Timing Diagram (ASCII)

Half-duplex turn-around:

```
DE (TX enable)  ────┐              ┌────────────
                  └──────────────┘

MCU TX          ────[ byte stream ]──────────────

Bus A-B diff    ────[ differential encoded ]──────

MCU RX          ────────────────[ response ]──────
                  ↑ quiet time ≥ 3.5 char
```

Modbus inter-frame gap: **3.5 character times** at current baud.

---

## Packet Format

RS-485 is physical layer only — payload is raw UART bytes. See [modbus.md](./modbus.md) for industrial framing.

| Layer | Content |
|-------|---------|
| RS-485 | Differential bits |
| UART | 8N1 typical |
| Application | Modbus, proprietary |

---

## Electrical Characteristics

| Parameter | Typical |
|-----------|---------|
| Nodes | up to 32 unit loads (more with repeaters) |
| Distance | 1200 m @ 9600 baud |
| Speed | 10 Mbit/s short / 9600 long |
| Common mode | −7 V to +12 V |
| Transceiver | SN65HVD1782 (3.3 V), MAX3485 |

Use **twisted pair** (one pair for A/B); **GND reference** required between nodes.

## Rust HAL Sketch

```rust
use esp_hal::gpio::{Output, Level};
use embedded_io::{Read, Write};

pub struct Rs485Uart<U> {
    uart: U,
    de: Output<'static>, // DE+RE tied together
}

impl<U: Read + Write> Rs485Uart<U> {
    pub fn transmit(&mut self, data: &[u8]) {
        self.de.set_high(); // enable driver
        let _ = self.uart.write_all(data);
        // wait TX complete (UART TC flag) before:
        self.de.set_low();  // enable receiver
    }

    pub fn receive(&mut self, buf: &mut [u8]) -> usize {
        self.uart.read(buf).unwrap_or(0)
    }
}
```

**Ownership:** `Rs485Uart` owns UART + DE pin; exclusive access prevents bus collisions.

## Bare-Metal Sketch (Concept)

Toggle GPIO for DE before writing UART DR register; poll TX empty flag before disabling driver.

## Common Mistakes

1. **Two masters transmitting** — garbled bus; implement collision detection or single master.
2. **DE lowered before last bit sent** — truncated frames.
3. **Missing termination** — reflections on long cables.
4. **No bias** — indeterminate idle level.
5. **Star wiring** — use linear bus topology.
