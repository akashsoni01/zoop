# MPU-9250 — 9-Axis IMU

The **MPU-9250** combines MPU-6500 (6-DoF) with AK8963 magnetometer on the same package. Access is via I²C/SPI with magnetometer behind an internal **I²C master**.

**Prerequisites:** [mpu6050.md](./mpu6050.md), [imu-overview.md](./imu-overview.md)

---

## Working Principle

- **Accel + Gyro** — same MEMS principles as MPU-6050 ([imu-overview.md](./imu-overview.md))
- **Magnetometer (AK8963)** — Hall-effect tri-axis, accessed through MPU's `I2C_SLV` interface

The MPU acts as bridge: your MCU talks to MPU registers; MPU forwards mag reads/writes to AK8963 at `0x0C`.

## Datasheet Key Points

| Parameter | Value |
|-----------|-------|
| WHO_AM_I (MPU) `0x75` | `0x71` (also reported as `0x73` on clones) |
| I²C address | `0x68` / `0x69` |
| Mag sensitivity | 0.15 µT/LSB (16-bit, ±4800 µT) |
| Interface | I²C or SPI |

---

## Protocol

### I²C (Primary)

Same as MPU-6050 for 6-DoF data registers (`0x3B`–`0x47`).

### Magnetometer Access Sequence

1. Enable I²C master in `USER_CTRL` (`0x6A`, bit 5)
2. Configure `I2C_MST_CTRL` for 400 kHz
3. Set slave 0 to AK8963 (`I2C_SLV0_ADDR = 0x0C | READ_BIT`)
4. Write mode to mag via slave registers, or use **bypass mode** (`INT_PIN_CFG` bit 1) to talk to mag directly at `0x0C`

**Bypass mode** (simpler for Rust): enable bypass, then use separate AK8963 driver on same I²C bus.

---

## Register Map (MPU + Mag Highlights)

| Addr | Name | Notes |
|------|------|-------|
| `0x6A` | USER_CTRL | I2C_MST_EN, FIFO reset |
| `0x37` | INT_PIN_CFG | BYPASS_EN for direct mag access |
| `0x75` | WHO_AM_I | `0x71` |
| AK8963 `0x0C` | WIA | Should read `0x48` |
| AK8963 `0x0A` | CNTL1 | Mode, bit depth |
| AK8963 `0x03`–`0x08` | HXL–HZH | Mag data (little-endian!) |

### AK8963 Power Modes (CNTL1)

| Mode | Value | Description |
|------|-------|-------------|
| Power-down | 0x00 | |
| Single measurement | 0x01 | Trigger one reading |
| Continuous 8 Hz | 0x02 | |
| Continuous 100 Hz | 0x06 | |
| Fuse ROM | 0x0F | Read ASA calibration |

Read **ASA** (`0x10`–`0x12` in fuse mode) for sensitivity adjust: `adjusted = raw * ((ASA - 128) / 256 + 1)`.

Identical to MPU-6050:

```
GPIO8 → SDA, GPIO9 → SCL, 3V3, GND
```

Keep module away from motor wires and speaker magnets.

## Rust Driver Sketch

```rust
use embedded_hal::i2c::I2c;

const MPU_ADDR: u8 = 0x68;
const MAG_ADDR: u8 = 0x0C;

pub struct Mpu9250<I2C> {
    i2c: I2C,
    mag_adj: [f32; 3],
}

impl<I2C, E> Mpu9250<I2C>
where
    I2C: I2c<Error = E>,
{
    pub fn enable_mag_bypass(&mut self) -> Result<(), E> {
        self.write_mpu(0x6A, 0x00)?; // disable I2C master
        let mut cfg = self.read_mpu(0x37)?;
        cfg |= 0x02; // BYPASS_EN
        self.write_mpu(0x37, cfg)?;
        Ok(())
    }

    pub fn init_mag(&mut self) -> Result<(), E> {
        self.enable_mag_bypass()?;
        // Fuse ROM read for ASA...
        self.write_mag(0x0A, 0x16)?; // 16-bit, 100 Hz continuous
        Ok(())
    }

    pub fn read_mag_uT(&mut self) -> Result<[f32; 3], E> {
        let mut st = [0u8; 1];
        self.i2c.read(MAG_ADDR, &mut st)?;
        if st[0] & 0x01 == 0 {
            return Err(/* overflow or not ready */);
```

## Bare-Metal Notes

- Mag data is **little-endian** (opposite of accel/gyro on MPU).
- Check **ST2** overflow bit before trusting reading.
- Run mag calibration figure-8 routine offline; store hard-iron offsets in flash.
- SPI mode: mag still requires I²C master or bypass — SPI-only MPU access is common.

---

## HAL / embedded-hal Notes

9-DoF fusion needs synchronized reads:

```rust
pub struct ImuSample {
    pub accel_g: [f32; 3],
    pub gyro_dps: [f32; 3],
    pub mag_uT: [f32; 3],
}
```

Pass `ImuSample` to Madgwick/Mahony filter (application layer).

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Mag always zero | Bypass not enabled | Set INT_PIN_CFG bit 1 |
| Heading jumps | Hard/soft iron | Calibrate; move from speakers |
| WHO_AM_I mismatch | Clone chip | Accept 0x73 or verify registers |
| Gyro OK, no mag | Separate I²C needed | Enable bypass or I2C_MST |
