# MPU-6050 — 6-Axis IMU (Accelerometer + Gyroscope)

The **InvenSense MPU-6050** is a widely available 6-DoF IMU on I²C. See [imu-overview.md](./imu-overview.md) for theory.

**Prerequisites:** [imu-overview.md](./imu-overview.md), [17-i2c.md](../17-i2c.md)

---

## Working Principle

Single-die integration of 3-axis MEMS accelerometer and 3-axis MEMS gyroscope with a digital motion processor (**DMP**) — the DMP is optional; most Rust projects read raw registers directly.

---

## Datasheet Key Points

| Parameter | Value |
|-----------|-------|
| VDD | 2.375–3.46 V |
| I²C address | `0x68` (AD0=0), `0x69` (AD0=1) |
| WHO_AM_I (`0x75`) | `0x68` |
| Gyro FSR | ±250, ±500, ±1000, ±2000 °/s |
| Accel FSR | ±2, ±4, ±8, ±16 g |

---

## Protocol

**I²C** up to 400 kHz. 16-bit registers are **big-endian** (high byte first).

Optional **INT** pin (active low): data ready, motion interrupt, FIFO overflow.

---

## Register Map (Essential)

| Addr | Name | Description |
|------|------|-------------|
| `0x6B` | `PWR_MGMT_1` | Sleep, clock source, reset |
| `0x6C` | `PWR_MGMT_2` | Disable axes |
| `0x1A` | `CONFIG` | DLPF setting |
| `0x1B` | `GYRO_CONFIG` | Gyro FSR (bits 4:3) |
| `0x1C` | `ACCEL_CONFIG` | Accel FSR (bits 4:3) |
| `0x23`–`0x24` | FIFO_EN | Enable sensors to FIFO |
| `0x43`–`0x48` | Sensor data | Gyro XYZ, Accel XYZ |
| `0x41`–`0x42` | TEMP | Temperature |
| `0x72`–`0x74` | FIFO | Count and data |
| `0x75` | WHO_AM_I | Device ID |

### PWR_MGMT_1 Init

Clear sleep bit (bit 6), set clock source to PLL (bits 2:0 = 1).

### Scaling (after FSR config)

| Accel FSR | LSB/g |
|-----------|-------|
| ±2g | 16384 |
| ±4g | 8192 |
| ±8g | 4096 |
| ±16g | 2048 |

| Gyro FSR | LSB/(°/s) |
|----------|-----------|
| ±250 | 131 |
| ±500 | 65.5 |
| ±1000 | 32.8 |
| ±2000 | 16.4 |

## ESP32-S3 Wiring

```
ESP32-S3          MPU-6050 Module
────────          ───────────────
GPIO8  (SDA) ───► SDA
GPIO9  (SCL) ───► SCL
3V3          ───► VCC
GND          ───► GND
GPIO7        ───► INT (optional)
```

AD0 pin: GND → address `0x68`, 3V3 → `0x69`.

## Rust Driver Sketch

```rust
use embedded_hal::i2c::I2c;

const ADDR: u8 = 0x68;
const REG_WHO_AM_I: u8 = 0x75;
const REG_PWR: u8 = 0x6B;
const REG_GYRO: u8 = 0x43;

pub struct Mpu6050<I2C> {
    i2c: I2C,
    accel_scale: f32,
    gyro_scale: f32,
}

impl<I2C, E> Mpu6050<I2C>
where
    I2C: I2c<Error = E>,
{
    pub fn init(&mut self) -> Result<(), E> {
        assert_eq!(self.read_u8(REG_WHO_AM_I)?, 0x68);
        self.write_u8(REG_PWR, 0x01)?;       // wake, PLL
        self.write_u8(0x1A, 0x03)?;          // DLPF ~44 Hz
        self.write_u8(0x1B, 0x00)?;          // gyro ±250 °/s
        self.write_u8(0x1C, 0x00)?;          // accel ±2g
        self.accel_scale = 16384.0;
        self.gyro_scale = 131.0;
        Ok(())
    }

    pub fn read_raw(&mut self) -> Result<([i16; 3], [i16; 3]), E> {
        let mut buf = [0u8; 14];
        self.i2c.write_read(ADDR, &[REG_GYRO], &mut buf)?;
        let gyro = parse_i16_triplet(&buf[0..6]);
        let accel = parse_i16_triplet(&buf[8..14]);
        Ok((gyro, accel))
    }
}

fn parse_i16_triplet(b: &[u8]) -> [i16; 3] {
    [
        i16::from_be_bytes([b[0], b[1]]),
        i16::from_be_bytes([b[2], b[3]]),
        i16::from_be_bytes([b[4], b[5]]),
    ]
}
```

**Crates:** `mpu6050`, `mpu6050-dmp` (DMP support limited in Rust).

## Bare-Metal Notes

- After reset, wait ≥100 ms before configuration.
- **Burst read** from `0x3B` (accel first layout) or `0x43` (gyro first) — pick one consistent map.
- Temperature: `T = 36.53 + (TEMP_OUT / 340.0)` °C.
- **FIFO mode** — buffer up to 1024 bytes for interrupt-driven sampling at low MCU duty cycle.

---

## HAL / embedded-hal Notes

Wire **INT pin** as `InputPin` with `PullUp`; on falling edge, burst-read FIFO in ISR or defer to main loop via `AtomicBool`.

```rust
use embedded_hal::digital::InputPin;

pub fn data_ready<P: InputPin>(&self, int: &mut P) -> Result<bool, P::Error> {
    Ok(int.is_low()?)
}
```

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| WHO_AM_I = 0x00 | No device, bad I²C | Check wiring, pull-ups |
| WHO_AM_I = 0x70 | MPU-9250 mag passthrough | Wrong chip or address mux |
| Drifting gyro | No bias cal | Subtract rest average |
| I²C hang | Clock stretch issues | Rare on MPU-6050; reduce speed to 100 kHz |
| Fake MPU-6050 | Counterfeit IC | Buy from reputable seller |

## Example Project: Fall Detector

1. Accel at 200 Hz (timer + poll or INT).
2. If magnitude > 2.5 g then < 0.5 g within 500 ms → "fall" event.
3. Log via `defmt`; blink NeoPixel red ([neopixel-ws2812.md](../displays/neopixel-ws2812.md)).
