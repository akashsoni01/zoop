# BMP280 — Barometric Pressure Sensor

The **Bosch BMP280** measures barometric pressure and temperature. Derived **altitude** (via barometric formula) makes it popular for drones and weather stations.

**Prerequisites:** [17-i2c.md](../17-i2c.md), [16-spi.md](../16-spi.md), [07-hal.md](../07-hal.md)

---

## Working Principle

BMP280 integrates a **piezo-resistive pressure sensing element** and a **temperature sensor** (for compensation) on one MEMS die. Factory-calibrated **trim coefficients** stored in OTP are read at init and used to compensate raw ADC values.

Outputs:

- Pressure (Pa or hPa)
- Temperature (°C)
- Derived altitude (m) — not measured directly

## Protocol

### I²C (Recommended)

Standard I²C write-then-read. Register addresses are 8-bit; burst read from `0xF7` returns pressure + temperature ADC bytes.

### SPI

CS active low. First bit of each byte is **read/write** (1 = read). SPI Mode 0 (CPOL=0, CPHA=0), max 10 MHz.

See [16-spi.md](../16-spi.md) for ESP32-S3 SPI setup.

## Register Map (Essential)

| Addr | Name | Access | Description |
|------|------|--------|-------------|
| `0xD0` | `chip_id` | R | Should read `0x58` |
| `0xE0`–`0xF0` | Trim | R | 24 calibration coefficients |
| `0xF4` | `ctrl_meas` | R/W | Mode + oversampling |
| `0xF5` | `config` | R/W | Standby, filter, SPI mode |
| `0xF7`–`0xFC` | Data | R | Press MSB..LSB, Temp MSB..LSB, XLSB |

### `ctrl_meas` (0xF4)

| Bits | Field | Notes |
|------|-------|-------|
| 7:5 | `osrs_t` | Temp oversampling (0–5) |
| 4:2 | `osrs_p` | Pressure oversampling |
| 1:0 | `mode` | 00 sleep, 01/02 forced, 11 normal |

### `config` (0xF5)

| Bits | Field |
|------|-------|
| 7:5 | `t_sb` standby in normal mode |
| 4:2 | `filter` IIR coefficient |
| 0 | `spi3w_en` 3-wire SPI |

## Calibration & Compensation

After reading trim registers, apply Bosch's integer compensation from datasheet §3.11.2. The algorithm uses `t_fine` (internal fixed-point) for both temperature and pressure.

```rust
// Simplified structure — see datasheet for full integer math
struct Bmp280Cal {
    t1: u16, t2: i16, t3: i16,
    p1: u16, p2: i16, p3: i16, p4: i16, p5: i16, p6: i16, p7: i16, p8: i16, p9: i16,
}
```

Altitude from pressure (international barometric formula, simplified):

```text
altitude ≈ 44330 × (1 - (P/P0)^(1/5.255))
```

Use `P0 = 101325` Pa at sea level; calibrate `P0` at known altitude for better relative readings.

## Rust Driver Sketch

```rust
use embedded_hal::i2c::I2c;

const CHIP_ID: u8 = 0x58;
const REG_ID: u8 = 0xD0;
const REG_CTRL: u8 = 0xF4;
const REG_DATA: u8 = 0xF7;

pub struct Bmp280<I2C> {
    i2c: I2C,
    addr: u8,
    cal: Bmp280Cal,
    t_fine: i32,
}

impl<I2C, E> Bmp280<I2C>
where
    I2C: I2c<Error = E>,
{
    pub fn new(i2c: I2C, addr: u8) -> Self {
        Self { i2c, addr, cal: Bmp280Cal::default(), t_fine: 0 }
    }

    pub fn init(&mut self) -> Result<(), E> {
        let id = self.read_reg(REG_ID)?;
        if id != CHIP_ID {
            return Err(/* InvalidChipId */);
        }
        self.cal = self.read_calibration()?;
        // Normal mode, OS x1 temp and pressure
        self.write_reg(REG_CTRL, 0b001_001_11)?;
        Ok(())
    }

    pub fn read(&mut self) -> Result<(f32, f32), E> {
        let mut buf = [0u8; 6];
        self.i2c.write_read(self.addr, &[REG_DATA], &mut buf)?;
        let adc_p = ((buf[0] as u32) << 12) | ((buf[1] as u32) << 4) | ((buf[2] as u32) >> 4);
        let adc_t = ((buf[3] as u32) << 12) | ((buf[4] as u32) << 4) | ((buf[5] as u32) >> 4);
        let temp = self.compensate_temp(adc_t);
        let press = self.compensate_press(adc_p);
        Ok((temp, press))
    }
}
```

**Crates:** `bmp280`, `bmp280-async` — prefer these over reinventing compensation.

## Bare-Metal Driver Notes

1. **Read trim once** at boot — store in RAM (~24 bytes).
2. **Wait after mode change** — first sample in forced mode needs `t_meas + t_press` (datasheet timing table).
3. **IIR filter** — set in `config` to reduce noise in normal mode; increases effective response time.
4. **Register auto-increment** — burst read from `0xF7` is atomic for one sample set.

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| I²C NACK | Wrong address | Scan bus; check SDO pin |
| `chip_id` ≠ 0x58 | Wrong chip (BME280?) | See [bme280.md](./bme280.md) — ID is `0x60` |
| Pressure drift | Heat from MCU | Mount sensor away from ESP32; enable IIR |
| Altitude wrong | Uncalibrated P0 | Store reference pressure at boot |
| SPI garbage | Wrong mode / 3-wire | Match `config` bit 0 to wiring |
