# ICM-20948 — 9-Axis IMU (TDK InvenSense)

The **ICM-20948** is the modern successor to MPU-9250: lower power, higher performance, with integrated **9-DoF** and optional **DMP** firmware.

**Prerequisites:** [imu-overview.md](./imu-overview.md), [mpu9250.md](./mpu9250.md)

---

## Working Principle

Same MEMS tri-axis accel/gyro plus AK09916 magnetometer (successor to AK8963). Uses **banked register map** — unlike MPU-6050's flat address space.

---

## Datasheet Key Points

| Parameter | Value |
|-----------|-------|
| WHO_AM_I (`0x00` bank 0) | `0xEA` |
| I²C address | `0x68` / `0x69` |
| Accel noise | Lower than MPU-6050 |
| Mag | AK09916 @ internal I²C |

---

## Protocol

**I²C** or **SPI**. Must select **register bank** via bits 5:4 of register `0x7F` (`REG_BANK_SEL`):

| Bank | Typical Content |
|------|-----------------|
| 0 | General config, WHO_AM_I |
| 1 | Gyro offset trim |
| 2 | Accel offset trim |
| 3 | I²C master (mag interface) |

Always set bank before read/write.

---

## Register Map (Bank 0 Essentials)

| Addr | Name | Description |
|------|------|-------------|
| `0x7F` | BANK_SEL | Select bank 0–3 |
| `0x00` | WHO_AM_I | `0xEA` |
| `0x06` | PWR_MGMT_1 | Sleep, reset, clock |
| `0x07` | PWR_MGMT_2 | Axis disable |
| `0x05` | LP_CONFIG | Low power accel |
| `0x2D` | ACCEL_CONFIG | FSR, DLPF |
| `0x2E` | GYRO_CONFIG_1 | FSR, DLPF |
| `0x2F`–`0x37` | Sensor data | Accel, gyro, temp |

Magnetometer via **I²C master** in bank 3 (similar to MPU-9250) or **external bypass** if broken out.

---

## ESP32-S3 Wiring

```
GPIO8 → SDA, GPIO9 → SCL, 3V3, GND
GPIO7 → INT1 (data ready recommended)
```

Use short I²C traces; ICM-20948 supports Fast Mode Plus (1 MHz) with proper pull-ups.

## Rust Driver Sketch

```rust
use embedded_hal::i2c::I2c;

const ADDR: u8 = 0x68;

pub struct Icm20948<I2C> {
    i2c: I2C,
    bank: u8,
}

impl<I2C, E> Icm20948<I2C>
where
    I2C: I2c<Error = E>,
{
    fn select_bank(&mut self, bank: u8) -> Result<(), E> {
        if self.bank != bank {
            self.i2c.write(ADDR, &[0x7F, bank << 4])?;
            self.bank = bank;
        }
        Ok(())
    }

    pub fn init(&mut self) -> Result<(), E> {
        self.select_bank(0)?;
        assert_eq!(self.read_reg(0x00)?, 0xEA);
        self.write_reg(0x06, 0x01)?; // auto clock
        self.delay_ms(10);
        self.write_reg(0x06, 0x01)?; // clear sleep
        // Configure accel/gyro FSR, enable mag via bank 3...
        Ok(())
    }
}
```

**Crates:** `icm20948`, `tca9536` (unrelated — check `icm20948` on crates.io).

## Bare-Metal Notes

- **Device reset** (`PWR_MGMT_1` bit 7): wait 100 ms after reset.
- Bank switching adds latency — batch operations per bank.
- **Offset registers** in banks 1/2 for factory trim and user calibration.
- DMP: proprietary firmware blob — limited Rust support; prefer raw reads + your fusion.

---

## HAL / embedded-hal Notes

Abstract banked access behind a small helper:

```rust
fn reg_read(&mut self, bank: u8, reg: u8) -> Result<u8, E> {
    self.select_bank(bank)?;
    self.read_reg(reg)
}
```

Async variant: use `embedded-hal-async` I2c for non-blocking reads in Embassy tasks.

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| WHO_AM_I wrong bank | Forgot BANK_SEL | Always select bank 0 first |
| Mag stuck | I²C master not configured | Follow AN for AK09916 bring-up |
| High idle current | Accel in low-noise vs duty-cycle | Set LP_CONFIG for wearable mode |
| SPI works, I²C not | SA0 address | Check AD0 pin |
