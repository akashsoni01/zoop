# MAX30102 — Pulse Oximeter / PPG

The **Maxim MAX30102** integrates **red and IR LEDs** with photodetector for **photoplethysmography (PPG)** — heart rate and SpO₂ estimation.

**Prerequisites:** [17-i2c.md](../17-i2c.md), [09-interrupts.md](../09-interrupts.md)

---

## Working Principle

**PPG:** LEDs shine through skin; blood volume changes modulate reflected/absorbed light. Red (~660 nm) and IR (~880 nm) channels capture pulsatile AC component on DC baseline.

**SpO₂** ratio-of-ratios uses AC/DC of red vs IR (calibration curve required — consumer modules use proprietary algorithms).

|-----------|-------|

| Sample rate | Up to 3200 sps (combined) |
| FIFO | 32 samples × 2 channels |
| VDD | 1.8 V core + 3.3 V LED supply typical |

## Protocol

Standard I²C register map. Burst read FIFO for efficient sampling.

---

## Register Map (Essential)

| Addr | Name | Description |
|------|------|-------------|
| `0x00` | INT_STATUS_1 | FIFO almost full, etc. |
| `0x01` | INT_STATUS_2 | |
| `0x02` | INT_ENABLE_1 | |
| `0x03` | INT_ENABLE_2 | |
| `0x04` | FIFO_WR_PTR | |
| `0x05` | FIFO_RD_PTR | |
| `0x06` | OVF_COUNTER | |
| `0x07` | FIFO_DATA | Burst read samples |
| `0x08` | FIFO_CONFIG | Sample averaging |
| `0x09` | MODE_CONFIG | SpO₂ vs HR only |
| `0x0A` | SPO2_CONFIG | ADC range, sample rate |
| `0x0C`–`0x0F` | LED currents | PA (red), PB (IR) |
| `0xFE` | REV_ID | Part revision |
| `0xFF` | PART_ID | Should be `0x15` |

### FIFO Sample Format

Each sample **3 bytes** × 2 channels (red then IR) — 18-bit value in 3 bytes (mask reserved bits per datasheet).

## Rust Driver Sketch

```rust
use embedded_hal::i2c::I2c;

const ADDR: u8 = 0x57;

pub struct Max30102<I2C> {
    i2c: I2C,
}

impl<I2C, E> Max30102<I2C>
where
    I2C: I2c<Error = E>,
{
    pub fn init(&mut self) -> Result<(), E> {
        self.write(0x09, 0x03)?; // shutdown reset
        self.write(0x09, 0x02)?; // SpO2 mode
        self.write(0x0A, 0x27)?; // 100 Hz, 411 µs, 18-bit
        self.write(0x0C, 0x24)?; // red LED current
        self.write(0x0D, 0x24)?; // IR LED current
        self.write(0x08, 0x4F)?; // FIFO avg 4, almost full 17
        Ok(())
    }

    pub fn read_fifo_sample(&mut self) -> Result<(u32, u32), E> {
        let mut b = [0u8; 6];
        self.i2c.write_read(ADDR, &[0x07], &mut b)?;
        let red = parse18(&b[0..3]);
        let ir = parse18(&b[3..6]);
        Ok((red, ir))
    }
}

fn parse18(b: &[u8]) -> u32 {
    ((b[0] as u32) << 16 | (b[1] as u32) << 8 | b[2] as u32) & 0x3_FFFF
}
```

## Bare-Metal Notes

- **FIFO interrupt** at 100 Hz — drain in ISR or defer; don't miss OVF.
- Apply **DC removal** (high-pass) before peak detection for HR.
- SpO₂ needs **calibration** — educational projects often show HR only.
- Motion artifacts dominate — advise user to hold still.

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Flat line | LED current low | Increase 0x0C/0x0D |
| Saturated | Too much pressure | Loosen finger contact |
| Noisy HR | Ambient light | Use enclosure; increase averaging |
| I²C fail | 1.8 V vs 3.3 V | Use level-shifted breakout |
