# RP2040 Board Guide (Raspberry Pi Pico)

Dual **Cortex-M0+** MCU with unique **PIO** (Programmable I/O) — excellent value and [22-embassy.md](../22-embassy.md) support.

---

## Overview

| Spec | Raspberry Pi Pico |
|------|-------------------|
| **CPU** | Dual Cortex-M0+ @ 125 MHz |
| **Flash** | 2 MB external (QSPI) |
| **SRAM** | 264 KB |
| **Debug** | SWD on test points; BOOTSEL USB |
| **PIO** | 8 state machines × 2 blocks |

---

## Memory Map Overview

```
0x0000_0000 ─── Boot ROM (USB MSC, flash boot)
0x1000_0000 ─── XIP flash (2 MB)
0x2000_0000 ─── SRAM 264 KB
0x4000_0000 ─── APB peripherals
0x5000_0000 ─── AHB (DMA, PIO, USB)
```

**SRAM bank** split: 4 × 64 KB + 8 KB — linker script places stack/heap; **embassy-rp** handles layout.

No MMU — flat memory model like all Cortex-M.

---

## GPIO Layout Notes

Pico pinout (selected):

| Pin | Function |
|-----|----------|
| **GP25** | Onboard LED |
| **GP0/GP1** | UART0 default |
| **GP4/GP5** | I²C0 / SPI0 options |
| **GP16/GP17/GP18/GP19** | SPI0 |
| **GP23** | Power sense |
| **GP24** | VBUS sense (USB host detect) |

**3.3 V IO** — not 5 V tolerant. **ADC** on GP26–29 (12-bit).

Multiplexing via **GPIO function select** registers — HAL sets `Function::SPI`, `Function::UART`, etc.

---

## Clock Tree

```
XOSC 12 MHz crystal
    │
    ▼
  PLL SYS ──► 125 MHz CPU
  PLL USB ──► 48 MHz USB
```

Internal **ring oscillator** for boot; switch to crystal in init. **clk_peri** feeds UART/SPI dividers — [15-uart.md](../15-uart.md).

---

## Boot Sequence

1. **Boot ROM** runs on reset.
2. If **FLASH CS** / BOOTSEL held → USB **Mass Storage Device** (UF2 drag-and-drop).
3. Else XIP from external flash.

Flash Rust firmware:

```bash
probe-rs run --chip RP2040 target/thumbv6m-none-eabi/debug/blink
# Or: elf2uf2 + copy to BOOTSEL drive
```

Second core (core1) starts via **SIO FIFO** launch — advanced concurrency.

## Flash & RAM

| | Pico |
|---|------|
| Flash | 2 MB QSPI |
| RAM | 264 KB |

Tight for large TLS stacks — fine for sensors, USB, PIO protocols. **Pico W** adds CYW43439 Wi-Fi — separate driver (`cyw43`), not native radio.

---

## Interrupt Vectors Overview

NVIC — 26 external IRQs + core exceptions:

| IRQ | Source |
|-----|--------|
| `IO_IRQ_BANK0` | GPIO |
| `UART0` | Serial |
| `SPI0/1` | SPI |
| `I2C0/1` | I²C |
| `DMA_IRQ_0` | DMA — [14-dma.md](../14-dma.md) |
| `USBCTRL_IRQ` | USB — [19-usb.md](../19-usb.md) |
| `PIO0/1_IRQ_0` | PIO state machines |

Both cores share NVIC — use **atomic** flags or assign core roles.

## PIO Note

PIO state machines run **independently of CPU** — assembly-like programs in `pio::PIO` module. Ideal when hardware lacks dedicated peripheral (e.g., WS2812 timing).
