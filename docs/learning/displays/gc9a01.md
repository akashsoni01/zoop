# GC9A01 — 240×240 Round TFT

The **GalaxyCore GC9A01** drives **circular 240×240** IPS displays — popular for dial/gauge UIs on wearables and knobs.

**Prerequisites:** [st7789.md](./st7789.md), [16-spi.md](../16-spi.md)

---

## Theory

Circular panel with **square 240×240 GRAM** — corners are masked physically but still exist in memory. Same **RGB565 SPI** paradigm as ST7789/ILI9341.

GC9A01 requires a **vendor-specific init sequence** (long table of register writes) — do not reuse ST7789 init blindly.

---

## Wiring (ESP32-S3, SPI)

```
GC9A01 Round Module   ESP32-S3
───────────────────   ────────
VCC  ───────────────► 3V3
GND  ───────────────► GND
CS   ◄────────────── GPIO10
DC   ◄────────────── GPIO14
RST  ◄────────────── GPIO15
SDA  ◄────────────── GPIO11 (MOSI)
SCL  ◄────────────── GPIO12 (SCK)
BL   ◄────────────── GPIO16
```

Physical round active area ≈ 240 mm diameter; treat (120,120) as center for gauge graphics.

---

## Protocol

SPI Mode 0, DC/RS for cmd vs data.

### Notable Commands

| Cmd | Purpose |
|-----|---------|
| `0xFE` / `0xEF` | Inter-register enable (GC9A01 specific) |
| `0x3A` | COLMOD — 16-bit color |
| `0x36` | MADCTL rotation |
| `0x2A`/`0x2B`/`0x2C` | Window + write |
| `0x11` | Sleep out (120 ms) |
| `0x29` | Display on |

Init includes **gamma curves** (`0xF0`–`0xF2` series) unique to GC9A01.

---

## Framebuffer Concepts

Full 240×240 RGB565 = 115 KB — use PSRAM or tile rendering.

**Circular clipping:** For gauges, compute `dx²+dy² ≤ r²` before drawing or accept corner pixels hidden by bezel.

```rust
fn in_circle(x: i32, y: i32, cx: i32, cy: i32, r: i32) -> bool {
    (x - cx).pow(2) + (y - cy).pow(2) <= r * r
}
```

Draw arc primitives with `embedded-graphics` `Arc` or `Prerendered` assets.

## Rust + embedded-graphics

```toml
[dependencies]
gc9a01 = "0.3"
embedded-graphics = "0.8"
embedded-graphics-framebuffer = "0.5"
display-interface-spi = "0.5"
```

```rust
use gc9a01::{Gc9a01, MODE};
use embedded_graphics::prelude::*;
use embedded_graphics::primitives::Circle;

let mut display = Gc9a01::new(spi, dc, rst, &mut delay).unwrap();
display.init().unwrap();

Circle::new(Point::new(60, 60), 100)
    .into_styled(PrimitiveStyle::with_stroke(Rgb565::RED, 4))
    .draw(&mut display)
    .unwrap();
```

Alternatively `mipidsi` may list GC9A01 model — verify init compatibility with your module.

## Common Mistakes

| Mistake | Symptom | Fix |
|---------|---------|-----|
| ST7789 init on GC9A01 | White/garbage | Use GC9A01 init table |
| Skip `0xFE` unlock | Commands ignored | Include vendor unlock sequence |
| Square assets in corners | Visible in bezel | Clip to circle |
| Wrong rotation | Upside-down dial | Adjust MADCTL |
| Backlight direct on GPIO | Dim/ hot GPIO | Use transistor for LED current |
