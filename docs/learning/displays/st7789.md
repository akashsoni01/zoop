# ST7789 — 240×240 / 135×240 IPS TFT

The **Sitronix ST7789** drives compact **IPS** color panels (240×240, 240×135, 170×320 variants) — popular on ESP32 display boards.

**Prerequisites:** [ili9341.md](./ili9341.md), [16-spi.md](../16-spi.md)

---

## Theory

Same fundamental **SPI TFT + GRAM** model as ILI9341 ([ili9341.md](./ili9341.md)):

- **RGB565** over SPI
- **MADCTL** for rotation
- Window address + RAMWR burst

IPS (In-Plane Switching) gives wide viewing angles — common on round and rectangular mini displays.

**Offset variants:** Some 240×240 modules use **240×320 GRAM** with y-offset 0 or 80 — check module vendor init.

---

## Wiring (ESP32-S3, SPI)

```
ST7789 Module       ESP32-S3
─────────────       ────────
VCC  ─────────────► 3V3
GND  ─────────────► GND
CS   ◄───────────── GPIO10
DC   ◄───────────── GPIO14
RST  ◄───────────── GPIO15
SDA  ◄───────────── GPIO11 (MOSI)
SCL  ◄───────────── GPIO12 (SCK)
BL   ◄───────────── GPIO16
```

240×135 boards (common ESP32-C3/S3 sticks) use same pins; resolution set in init.

---

## Protocol

SPI Mode 0/3 (module dependent — Mode 0 most common).

### ST7789-Specific Commands

| Cmd | Name | Notes |
|-----|------|-------|
| `0x11` | SLPOUT | 120 ms delay after |
| `0x3A` | COLMOD | `0x05` or `0x55` for 16-bit |
| `0x36` | MADCTL | Rotation |
| `0x2A`/`0x2B` | CASET/RASET | Window |
| `0x2C` | RAMWR | Pixel data |
| `0x21` | INVON | Some IPS modules need inversion |
| `0x13` | NORON | Normal display mode |

Init tables often include **manufacturer-specific** `0xB0`–`0xF0` gamma registers.

## Framebuffer Concepts

| Resolution | Full RGB565 buffer |
|------------|-------------------|
| 240×240 | 115,200 B (~112 KB) |
| 240×135 | 64,800 B (~63 KB) |

**Recommended:** 240×N **line buffer** (N=10–40) streamed with DMA.

```rust
// Tile flush pattern
for tile_y in (0..height).step_by(TILE_H) {
    draw_scene_to_tile(&mut tile_buf, tile_y);
    set_address_window(0, tile_y, 239, tile_y + TILE_H - 1);
    spi_dma_write(&tile_buf);
}
```

## Rust + embedded-graphics

```toml
[dependencies]
st7789 = "0.7"
# or
mipidsi = "0.8"
embedded-graphics = "0.8"
```

```rust
use st7789::{Orientation, ST7789};
use embedded_graphics::mono_font::{ascii::FONT_10X20, MonoTextStyle};
use embedded_graphics::text::Text;
use embedded_graphics::prelude::*;

let mut display = ST7789::new(spi, dc, rst, 240, 240, Orientation::Portrait);
display.init(&mut delay).unwrap();
display.fill_solid(&mut display.bounding_box(), Rgb565::BLACK).unwrap();

Text::new("ST7789", Point::new(40, 120), MonoTextStyle::new(&FONT_10X20, Rgb565::WHITE))
    .draw(&mut display)
    .unwrap();
```

`mipidsi` supports ST7789 model variants — specify correct display size.

## Common Mistakes

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Wrong height in init | Scrolled/garbled | Use 240 vs 135 init table |
| Missing INVON | Negative image | Add `0x21` per module doc |
| y-offset ignored | Status bar clipped | Apply `y_offset=80` for some 240×240 |
| COLMOD 0x05 vs 0x55 | Color stripes | Match crate to module |
| Insufficient SLPOUT delay | Blank | Wait 120 ms after sleep out |
